Electron 技术实践文档

📖 文档概述

本文档详细介绍了在AI 虚拟人智慧大屏项目中 Electron 技术的实践应用，包括主进程架构、渲染进程通信、窗口管理、文件系统操作、本地服务集成等核心功能的实现。

🏗️ 项目架构

技术栈

Electron版本：23.3.13
Vue CLI Plugin：vue-cli-plugin-electron-builder ~2.1.1
构建工具：electron-builder
Node版本：16.x

1. 主进程架构设计

1.1 入口文件结构

// src/background.ts
import { app, BrowserWindow, ipcMain } from "electron";
import { createProtocol } from "vue-cli-plugin-electron-builder/lib";
import { runServer, closeServer } from "./service";

// 窗口实例
let win: Electron.BrowserWindow | null = null;
let workerWin: Electron.BrowserWindow | null = null;
let loadingWin: Electron.BrowserWindow | null = null;

// 应用生命周期管理
app.on("ready", async () => {
  await runServer(); // 启动本地服务
  createWindow(); // 创建主窗口
});

app.on("will-quit", async (e) => {
  e.preventDefault();
  await closeServer(); // 关闭本地服务
  app.quit();
});

1.2 单例应用控制

// 确保应用只有一个实例运行
if (!app.requestSingleInstanceLock()) {

// 处理第二个实例的启动
app.on("second-instance", () => {
  if (win) {
    if (win.isMinimized()) win.restore();
    win.focus();
  }
});

2. 窗口管理

2.1 主窗口创建

function createWindow() {
  win = new BrowserWindow({
    width: 540,
    height: 990,
    backgroundColor: "#f4f4ff",
    show: false, // 初始不显示
    frame: false, // 无边框窗口
    webPreferences: {
      nodeIntegration: process.env.ELECTRON_NODE_INTEGRATION as boolean,
      contextIsolation: !process.env.ELECTRON_NODE_INTEGRATION,
      preload: path.join(__static, "preload.js"),
      webSecurity: false, // 允许跨域（开发环境）
    },
  });

  // 设置窗口宽高比
  win.setAspectRatio(6 / 11);

  // 加载内容
  if (process.env.WEBPACK_DEV_SERVER_URL) {
    win.loadURL(process.env.WEBPACK_DEV_SERVER_URL);
  } else {
    createProtocol("app");
    win.loadURL("app://./index.html");
  }

  // 窗口准备显示时
  win.on("ready-to-show", () => {
    closeLoadingWindow();
    win?.show();
  });
}

3. IPC 通信机制

3.1 预加载脚本

// public/preload.js
const { contextBridge, ipcRenderer } = require("electron");

// 暴露安全的API到渲染进程
contextBridge.exposeInMainWorld("ipc", {
  // 发送消息（不等待响应）
  send: (channel, data) => {
    ipcRenderer.send(channel, data);
  },

  // 发送消息并等待响应
  invoke: (channel, data) => {
    return ipcRenderer.invoke(channel, data);
  },

  // 监听消息
  on: (channel, callback) => {
    ipcRenderer.on(channel, (event, ...args) => {
      callback(...args);
    });
  },

  // 移除监听
  removeAllListeners: (channel) => {
    ipcRenderer.removeAllListeners(channel);
  },
});

// 暴露文件路径
contextBridge.exposeInMainWorld("exePath", "");

3.2 渲染进程通信封装

// src/modules/rendererIpc.ts
declare global {
  interface Window {
    ipc: {
      send: (channel: string, data?: any) => void;
      invoke: (channel: string, data?: any) => Promise<any>;
      on: (channel: string, callback: (...args: any[]) => void) => void;
      removeAllListeners: (channel: string) => void;
    };
    exePath: string;
  }
}

// 封装IPC调用
export const rendererIpc = {
  // 关闭窗口
  closeWindow: () => {
    window.ipc.send("window_close");
  },

  // 获取下载文件
  getDownloadFiles: (urls: string[]): Promise<Record<string, string>> => {
    return window.ipc.invoke("window_get_download", urls);
  },

  // 检查下载文件
  checkDownloadFiles: (urls: string[]): Promise<string[]> => {
    return window.ipc.invoke("window_check_download", urls);
  },
};

3.3 双向通信示例

主进程 → 渲染进程：

// 主进程发送
win.webContents.send("get-exe-path", app.getPath("exe"));

// 渲染进程接收
window.ipc.on("get-exe-path", (path: string) => {
  window.exePath = path;
});

渲染进程 → 主进程：

// 渲染进程发送
window.ipc.invoke("get_xmov_config");

// 主进程处理
ipcMain.handle("get_xmov_config", () => {
  const electronConfig = new ElectronConfig("./modelPath/model.gbl");
  return electronConfig.get();
});

4. 文件系统操作

4.1 文件下载管理

// 使用electron-extension封装的下载功能
import { ElectronDownload } from "@xmov/electron-extension";

let electronDownload: ElectronDownload | null = null;

// 初始化下载器
electronDownload = new ElectronDownload(win);

// 下载文件
ipcMain.on("window_download_start", (e, url: string) => {
  if (!win || !electronDownload) return;

  electronDownload.download(url, downloadPath).finally(() => {
    win?.webContents.send("window_download_end");
  });

  // 下载进度回调
  electronDownload.onProgress = (item: any) => {
    win?.webContents.send("window_download_progress", item.progress);
  };
});

4.2 文件路径管理

// 开发环境和生产环境的路径处理
const isDevelopment = process.env.NODE_ENV === "development";
const downloadPath = isDevelopment
  ? path.resolve(app.getPath("videos")) // 开发：系统视频目录
  : path.resolve(app.getPath("exe"), "../", "download"); // 生产：应用目录

// 获取可执行文件路径
ipcMain.handle("get_exe_path", () => {
  return app.getPath("exe");

4.3 文件检查

// 检查文件是否存在
ipcMain.handle("window_check_download", (e, urls: string[]) => {
  return urls.filter((url: string) => {
    const fileName = url.split("/").pop() || "";
    const filePath = path.resolve(downloadPath, fileName);
    return fileName && !fs.existsSync(filePath);
  });
});

// 获取已下载文件的本地路径
ipcMain.handle("window_get_download", (e, urls: string[]) => {
  const cacheMap: Record<string, string> = {};
  urls.forEach((url: string) => {
    const fileName = url.split("/").pop() || "";
    const filePath = path.resolve(downloadPath, fileName);
    cacheMap[url] = "xmov://" + filePath; // 使用自定义协议
  });
  return cacheMap;
});

5. 本地服务集成

5.1 服务启动管理

// src/service.ts
import { app } from "electron";
import path from "path";
import { exec } from "child_process";
import { ElectronLogger } from "@xmov/electron-extension";

// 获取服务路径
let appPath = app.getPath("exe");
let serverPath = app.isPackaged
  ? path.resolve(appPath, "../server/main")
  : path.resolve(__dirname, "../public/server/main");

// 启动本地服务
export function runServer() {
  const cmdStr = `${WAKEUP_EXE_NAME} --host 0.0.0.0 --port ${LOCAL_SERVER_PORT}`;

  fs.stat(serverPath, (err) => {
    if (err) {
      ElectronLogger.error("服务启动失败:", err);
    } else {
      runExec(serverPath);
      ElectronLogger.debug("服务启动成功");
    }
  });
}

function runExec(path: string) {
  const workerProcess = exec(cmdStr, { cwd: path });

  workerProcess.stdout.on("data", (data) => {
    ElectronLogger.debug("stdout: " + data);
  });

  workerProcess.stderr.on("data", (data) => {
    ElectronLogger.debug("stderr: " + data);
  });

  workerProcess.on("close", (code) => {
    ElectronLogger.debug("进程退出，代码: " + code);
  });
}

5.2 服务关闭管理

// 关闭本地服务
export function closeServer(callback?: Function) {
  return promiseExec(`cmd /c taskkill /f /t /im ${WAKEUP_EXE_NAME}`)
    .then((result) => {
      ElectronLogger.info("服务已关闭");
      callback?.();
    })
    .catch((err) => {
      ElectronLogger.error("关闭服务失败:", err);
      callback?.();
    });
}

// 优雅退出
app.on("will-quit", (e) => {
  e.preventDefault();
  closeServer().finally(() => {
    app.quit();
  });
});

🔧 常见问题解决

1. 白屏问题

原因：WebSecurity 阻止了资源加载

解决：

webPreferences: {
  webSecurity: false; // 开发环境
}

2. IPC 通信失败

原因：contextIsolation 启用但 preload 未正确暴露 API

解决：检查 preload.js 中的 contextBridge 使用

3. 文件路径问题

原因：开发和生产环境路径不一致

解决：使用 app.isPackaged 判断环境

4. 服务启动失败

原因：服务进程未正确关闭

解决：确保在 will-quit 事件中关闭服务

📚 最佳实践总结

  1. 安全性：始终启用 contextIsolation，通过 preload 暴露 API
  2. 性能：合理使用硬件加速，及时释放资源
  3. 稳定性：完善的错误处理和日志记录
  4. 可维护性：清晰的代码结构和注释
  5. 用户体验：平滑的启动流程和加载提示
