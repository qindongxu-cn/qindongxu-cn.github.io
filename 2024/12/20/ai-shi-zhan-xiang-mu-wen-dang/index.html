AI 实战项目文档

📖 项目概述

AI 虚拟人智慧大屏 是一个基于多模态 AI 技术的智能交互系统，通过语音识别、人脸识别、数字人对话等技术，为线下场景（展厅、商场、营业厅等）提供智能化服务。本项目采用 Vue 3 + Electron 架构，实现了完整的 AI 交互闭环。

核心特性

  • 🎤 实时语音识别（ASR）：支持多种 ASR 引擎，可插拔式架构
  • 👤 人脸识别与跟踪：实时人脸检测、情绪识别、视线跟踪
  • 🤖 数字人对话：自然语言理解、多轮对话、上下文感知
  • 🎨 多模态交互：语音、视觉、触控等多种交互方式融合
  • 🔄 可扩展架构：支持多种 AI 服务提供商切换

🏗️ 技术架构

技术栈

前端框架：Vue 3 (Composition API)
桌面框架：Electron 23.x
类型系统：TypeScript 4.x
状态管理：Vuex 4 + vuex-module-decorators
路由管理：Vue Router 4
UI框架：WindiCSS
构建工具：Vue CLI 4.5

🎯 核心功能实现

1. 可插拔 ASR 系统

1.1 架构设计

项目实现了可插拔的 ASR（自动语音识别）架构，支持在不同 ASR 引擎间无缝切换。

核心文件结构：

src/
├── interfaces/
│   └── IAsrProvider.ts          # 统一接口定义
├── providers/
│   ├── ProviderFactory.ts       # 工厂模式创建提供者
│   ├── WalleProvider.ts         # Walle引擎适配器
│   └── TencentAsrProvider.ts    # 腾讯云ASR适配器
├── hooks/
│   └── usePluggableAsr.ts       # 统一Hook层
└── config/
    └── pluggable-asr.config.ts  # 配置管理

1.2 接口抽象层

通过 IAsrProvider 接口统一不同 ASR 服务的实现：

export interface IAsrProvider {
  // 状态属性
  readonly asrText: string;
  readonly asrState: AsrState;
  readonly faceDetected: boolean;
  readonly faceData: FaceDetectionResult | null;

  // 生命周期
  init(config: ProviderConfig): Promise<void>;
  destroy(): Promise<void>;

  // ASR控制
  startAsr(): Promise<void>;
  stopAsr(): Promise<void>;

  // 人脸识别控制
  startFaceDetection(): Promise<void>;
  stopFaceDetection(): Promise<void>;

  // 回调设置
  setCallbacks(callbacks: {
    onAsrStart?: AsrStartCallback;
    onAsrResult?: AsrCallback;
    onAsrUpdate?: AsrUpdateCallback;
    onFaceDetected?: FaceCallback;
    onTimeout?: TimeoutCallback;
    onError?: ErrorCallback;
  }): void;
}

1.3 提供者实现

WalleProvider（推荐方案）：

  • ✅ 统一的 WebSocket 通信
  • ✅ 实时视频/音频流处理
  • ✅ 内置人脸识别能力
  • ✅ 低延迟语音识别

TencentAsrProvider（备选方案）：

  • ✅ 腾讯云实时语音识别
  • ✅ 高准确率识别
  • ✅ 多语言支持

1.4 使用示例

import { usePluggableAsr } from "@/hooks/usePluggableAsr";
import { ProviderType } from "@/interfaces/IAsrProvider";

const voiceStart = ref(false);

// 初始化可插拔ASR
const {
  currentProvider,
  asrText,
  asrState,
  switchProvider,
  init,
  startAsr,
  stopAsr,
} = usePluggableAsr(voiceStart, {
  defaultProvider: ProviderType.WALLE,
  autoInit: false,
});

// 初始化Walle引擎
await switchProvider(ProviderType.WALLE, {
  serverUrl: "ws://localhost:39999",
  videoCanvas: canvasElement,
  renderOptions: {
    fps: { layout: [10, 10], size: 16 },
  },
});

// 设置回调
setCallbacks({
  onAsrResult: (result) => {
    console.log("识别结果:", result.text);
    // 发送给数字人进行回复
  },
  onFaceDetected: (result) => {
    console.log("检测到人脸:", result.faceCount);
  },
});

// 启动ASR
await startAsr();

2. 人脸识别系统

2.1 人脸检测流程

// Walle引擎自动提供人脸检测信息
this.walleClient.subject("videoframe").subscribe((frameInfo: any) => {
  const { has_face, face_num, face_x, face_y, face_w, face_h } = frameInfo;

  // 更新检测状态
  this.faceDetected = has_face && face_num > 0;

  // 绘制人脸框
  if (has_face && canvasContext) {
    canvasContext.strokeStyle = "rgba(0, 255, 0, 0.9)";
    canvasContext.strokeRect(face_x, face_y, face_w, face_h);
  }
});

2.2 人脸识别优化策略

  • 平滑处理：使用连续检测计数避免抖动
  • 阈值控制：可配置的置信度阈值
  • 性能优化：控制检测频率，避免过度消耗资源
// 人脸检测平滑处理
private consecutiveHasFace: number = 0
private consecutiveNoFace: number = 0
private hasFaceTotal: number = 1
private noFaceTotal: number = 15

// 只有连续检测到一定次数才认为有人脸
if (has_face) {
  this.consecutiveHasFace++
  this.consecutiveNoFace = 0
  if (this.consecutiveHasFace >= this.hasFaceTotal) {
    this.faceDetected = true
  }
} else {
  this.consecutiveNoFace++
  this.consecutiveHasFace = 0
  if (this.consecutiveNoFace >= this.noFaceTotal) {
    this.faceDetected = false
  }
}

4. 错误处理与重试机制

// 重试机制
const withRetry = async <T>(
  operation: () => Promise<T>,
  maxRetries: number = 3
): Promise<T> => {
  for (let attempt = 0; attempt <= maxRetries; attempt++) {
    try {
      return await operation();
    } catch (error) {
      if (attempt === maxRetries) throw error;
      await new Promise((resolve) => setTimeout(resolve, 400));
    }
  }
  throw new Error("重试失败");
};

📊 性能优化

1. 内存管理

  • 及时释放 VideoFrame：使用 frame.close() 释放内存
  • 限制并发连接：同一时间只允许一个 ASR 连接
  • 清理定时器：组件销毁时清理所有定时器

2. 网络优化

  • WebSocket 连接池：复用 WebSocket 连接
  • 数据压缩：对传输的数据进行压缩
  • 断线重连：自动重连机制

3. 渲染优化

  • Canvas 缓存：复用 Canvas 元素
  • 帧率控制：限制最大帧率，避免过度渲染
  • 按需渲染：只在可见时才进行渲染
