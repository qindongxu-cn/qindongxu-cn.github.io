项目概览

项目简介

Youyan Multi 是一个基于 Monorepo 架构的多端应用项目，主要包含：

  • Platform（服务平台）：基于 Nuxt 3 的 SSR 应用，面向 C 端用户的官网和营销页面
  • Workspace（工作台）：基于 Vite + Vue 3 的 SPA 应用，用户工作空间
  • Common（公共库）：共享的业务逻辑、类型定义、API 接口等
  • Design（设计系统）：UI 组件库和设计规范

项目特点

  • 🌍 国际化支持：支持中文（CN）和海外（US）两个区域版本
  • 🎨 多主题：支持明暗主题切换
  • 📱 响应式设计：支持 PC 和移动端
  • 🚀 性能优化：SSR、代码分割、CDN 部署
  • 🔐 权限管理：完善的用户权限和组织架构管理

Monorepo 架构说明

本项目采用 pnpm workspace 实现 Monorepo：

# pnpm-workspace.yaml
packages:
  - "app/*"
  - "packages/*"

优势：

  • 代码复用：共享组件和逻辑
  • 统一依赖：锁定版本，减少冲突
  • 开发效率：一键安装、构建、发布
  • 类型安全：workspace 内部依赖类型完整

代码规范

编码规范

1. CSS/样式规范

优先使用 BEM 规范，且让 AI 帮你生成名字，不要自己写。

不要使用 prompt，因为项目的全埋点依赖清晰的 class 内容。

2. 国际化规范

✅ 所有中文文本必须使用 i18n：

操作流程：

  1. 编写中文文本
  2. 使用 i18n Ally 插件（VSCode）提取到 locale 文件
  3. 补充英文翻译

locale 文件位置：

  • Platform: app/platform/locales/langs/zh-CN.json, en-US.json
  • Workspace: app/workspace/src/locales/zh-CN.json, en-US.json
  • Common: packages/common/src/locales/zh-CN.json, en-US.json

3. API 命名规范

✅ API 方法命名与后端路径对齐：

// app/platform/api/module/order.ts
// 后端接口：GET /order/coin_list
export const getOrderCoinList = (params: any) => {
  return request.get("/order/coin_list", { params });
};

// 后端接口：POST /order/create
export const postOrderCreate = (data: any) => {
  return request.post("/order/create", data);
};

// 后端接口：PUT /order/update
export const putOrderUpdate = (data: any) => {
  return request.put("/order/update", data);
};

// 后端接口：DELETE /order/delete
export const deleteOrder = (id: string) => {
  return request.delete(`/order/delete/${id}`);
};

命名规则：

  • 使用 HTTP method 开头：get、post、put、delete、patch
  • 路径转换为驼峰：/order/coin_list → getOrderCoinList
  • 便于 AI 代码补全（Codeium、Copilot 等）

4. TypeScript 规范

✅ 推荐：

// 定义接口类型
interface UserInfo {
  id: string;
  name: string;
  avatar?: string;
  role: "admin" | "user" | "guest";
}

// 使用泛型
function fetchData<T>(url: string): Promise<T> {
  return fetch(url).then((res) => res.json());
}

// 使用联合类型
type Status = "pending" | "success" | "error";

❌ 避免：

// 避免使用 any
function fetchData(url: string): Promise<any> {}

// 避免过度使用可选链
const name = user?.info?.profile?.name?.firstName;

2. 状态管理（Pinia）

Store 结构

packages/common/src/store/
├── index.ts          # Store 导出

示例：User Store

// packages/common/src/store/user.ts
import { defineStore } from "pinia";

export const useUserStore = defineStore("user", () => {
  // State
  const userInfo = ref<UserInfo | null>(null);
  const token = ref<string>("");

  // Getters
  const isLoggedIn = computed(() => !!token.value);
  const userName = computed(() => userInfo.value?.name || "");

  // Actions
  const login = async (credentials: LoginParams) => {
    const res = await postAuthLogin(credentials);
    token.value = res.token;
    userInfo.value = res.userInfo;
    setToken(res.token);
  };

  const logout = () => {
    token.value = "";
    userInfo.value = null;
    removeToken();
  };

  return {
    userInfo,
    token,
    isLoggedIn,
    userName,
    login,
    logout,
  };
});

3. API 请求封装

请求拦截器

// app/platform/api/request.ts
import axios from "axios";

const request = axios.create({
  baseURL: process.env.NUXT_PUBLIC_API_BASE,
  timeout: 30000,
});

// 请求拦截
request.interceptors.request.use((config) => {
  const token = getToken();
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截
request.interceptors.response.use(
  (response) => {
    const { code, data, msg } = response.data;
    if (code === 200) {
      return data;
    } else {
      message.error(msg);
      return Promise.reject(new Error(msg));
    }
  },
  (error) => {
    if (error.response?.status === 401) {
      // 跳转登录
      router.push("/login");
    }
    return Promise.reject(error);
  }
);

export default request;

权限枚举

// 用户角色
export enum USER_ADMIN {
  SUPER_ADMIN = 1, // 超级管理员
  ORG_ADMIN_USER = 2, // 组织管理员
  MANAGEMENT_PLATFORM = 3, // 平台管理员

// 用户等级
export enum USER_LEVEL_KEY {
  TASTE = 1, // 体验版
  PERSONAL = 2, // 个人版
  TEAM_LIGHT = 3, // 团队轻量版
  ORG_STANDARD = 4, // 企业标准版
  ORG_FLAGSHIP = 5, // 企业旗舰版
}

权限判断

// packages/common/src/store/permission.ts
export const usePermissionStore = defineStore("permission", () => {
  const userStore = useUserStore();

  // 检查是否有权限
  const hasPermission = (requiredRole: USER_ADMIN) => {
    return userStore.userInfo?.role === requiredRole;
  };

  // 检查用户等级
  const hasLevel = (requiredLevel: USER_LEVEL_KEY) => {
    return userStore.userInfo?.level >= requiredLevel;
  };

  return { hasPermission, hasLevel };
});

5. 国际化（i18n）

配置

Platform（Nuxt）：

// app/platform/plugins/00.boot.ts
import { createI18nService } from "@rendora/common/services/i18n";
import CHS from "../locales/langs/zh-CN.json";
import EN from "../locales/langs/en-US.json";

const i18nSrv = createI18nService({

  globalInjection: true,
  defaultLocale: isChinese() ? "zh-CN" : "en-US",
  messages: {
    "zh-CN": CHS,
    "en-US": EN,
  },

await i18nSrv.initialize(vueApp);

  legacy: false,
  locale: "zh-CN",

    "zh-CN": zhCN,

  },

app.use(i18n);

6. OSS 文件上传

配置

// app/platform/nuxt.config.ts
nuxtOss: {
  ossRoot: `youyan-service-platform/${process.env.NUXT_PUBLIC_ENV}`,
  region: process.env.NUXT_PUBLIC_AREA === 'CN'
    ? 'oss-cn-hangzhou'
    : 'oss-cn-hongkong',
  accessKeyId: 'YOUR_ACCESS_KEY_ID',
  accessKeySecret: 'YOUR_ACCESS_KEY_SECRET',
  bucket: process.env.NUXT_PUBLIC_AREA === 'CN'
    ? 'fe-assets-oss'
    : 'fe-assets-oss-hk',
}

使用

// packages/common/src/composables/useOSSUpload.ts
import OSS from "ali-oss";

export const useOSSUpload = () => {
  const client = new OSS({
    region: "oss-cn-hangzhou",
    accessKeyId: "xxx",
    accessKeySecret: "xxx",
    bucket: "your-bucket",
  });

  const uploadFile = async (file: File, path: string) => {
    try {
      const result = await client.put(path, file);
      return result.url;
    } catch (error) {
      console.error("上传失败", error);
      throw error;
    }
  };

  return { uploadFile };
};

常见问题

1. 依赖安装问题

问题： pnpm install 失败

解决：

# 清理缓存
pnpm store prune

# 删除 node_modules
rm -rf node_modules

# 删除 lock 文件（谨慎）
rm pnpm-lock.yaml

# 重新安装
pnpm install

2. 端口占用

问题： 端口 3000 或 8888 被占用

解决：

# 查找占用进程（Windows）
netstat -ano | findstr :3000

# 杀死进程
taskkill /PID <PID> /F

# 或修改端口
# Platform: nuxt.config.ts -> devServer.port
# Workspace: vite.config.ts -> server.port

3. TypeScript 类型错误

问题： 导入 workspace 包时类型找不到

解决：

// tsconfig.json
{
  "compilerOptions": {
    "paths": {
      "@rendora/common/*": ["../../packages/common/src/*"],
      "@rendora/design/*": ["../../packages/design/src/*"]
    }
  }
}

4. 样式不生效

问题： TailwindCSS 类名不生效

解决：

检查 tailwind.config.js 的 content 配置：

module.exports = {
  content: [
    "./src/**/*.{vue,js,ts,jsx,tsx}",
    "../../packages/common/src/**/*.{vue,js,ts,jsx,tsx}",
    "../../packages/design/src/**/*.{vue,js,ts,jsx,tsx}",
  ],
};

5. 跨域问题

问题： 本地开发 API 请求跨域

解决：

内网开发已开启跨域，无需配置。如遇特殊情况，使用 whistle.js 代理：

# 安装 whistle
npm install -g whistle

# 启动
w2 start

# 配置规则（whistle 界面）
api.example.com 127.0.0.1:3000

6. Nuxt 构建错误

问题： nuxt build 失败

解决：

清理缓存

rm -rf .nuxt .output node_modules/.cache

检查动态导入

确保所有异步组件正确导入：

// ✅ 正确
component: () => import("~/pages/home/index.vue");

// ❌ 错误
component: require("~/pages/home/index.vue");

7. i18n 提取失败

问题： i18n Ally 无法提取文本

解决：

  • 检查 .vscode/settings.json 配置
  • 确保安装了 i18n Ally 插件
  • 重启 VSCode

8. Git Hooks 不生效

问题： 提交时没有触发 lint 检查

解决：

# 重新安装 husky
pnpm run prepare

# 检查 .husky 目录
ls -la .husky

# 确保脚本有执行权限
chmod +x .husky/*

部署方式

1. Nginx 部署

Platform（SSR）：

# 启动 Nuxt 服务
node .output/server/index.mjs

Nginx 配置：

server {
  listen 80;
  server_name youyan3d.com;

  location / {
    proxy_pass http://localhost:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection 'upgrade';
    proxy_set_header Host $host;
    proxy_cache_bypass $http_upgrade;
  }
}

Workspace（SPA）：

Nginx 配置：

server {
  listen 80;
  server_name workspace.youyan3d.com;
  root /var/www/workspace/dist;
  index index.html;

  location / {
    try_files $uri $uri/ /index.html;
  }

  # 静态资源缓存
  location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2|ttf)$ {
    expires 1y;
    add_header Cache-Control "public, immutable";
  }
}

2. Docker 部署

Platform Dockerfile：

# app/platform/dockerfile
FROM node:20-alpine
WORKDIR /app
COPY .output /app/.output
ENV HOST=0.0.0.0
ENV PORT=3000
EXPOSE 3000
CMD ["node", ".output/server/index.mjs"]

Workspace Dockerfile：

# app/workspace/dockerfile
FROM nginx:alpine
COPY dist /usr/share/nginx/html
COPY nginx.conf /etc/nginx/conf.d/default.conf
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

构建和运行：

# Platform
docker build -t youyan-platform -f app/platform/dockerfile app/platform
docker run -p 3000:3000 youyan-platform

# Workspace
docker build -t youyan-workspace -f app/workspace/dockerfile app/workspace
docker run -p 80:80 youyan-workspace

安装 PM2：

npm install -g pm2

// app/platform/ecosystem.config.cjs
module.exports = {
  apps: [

      name: "youyan-platform",
      script: ".output/server/index.mjs",
      instances: "max",
      exec_mode: "cluster",
      env: {
        NODE_ENV: "production",

      },

cd app/platform
pm2 start ecosystem.config.cjs
pm2 save
