有灵离线数字人 JS-SDK 系统架构文档

📖 SDK 概述

有灵离线数字人 JS-SDK 是一个用于在 Web 环境中集成 3D 数字人的 JavaScript SDK。该 SDK 提供了完整的数字人渲染、动画控制、语音交互等功能，支持离线模式和网络重连机制。

主要特性

  • 🎭 3D 数字人渲染: 支持身体动画、表情动画、唇形同步
  • 📱 跨平台支持: 支持主流浏览器环境
  • 🌐 网络自适应: 自动检测网络状态，支持离线/在线模式切换
  • 📊 调试支持: 内置调试面板和性能监控
  • 💾 智能缓存: LRU 缓存策略，优化资源加载

🔧 核心模块说明

1. XmovAvatar (主类)

SDK 的核心入口类，负责协调所有模块的工作。

主要职责:

  • 初始化 SDK 配置: 验证配置参数，初始化各个模块
  • 管理 SDK 生命周期: 控制 SDK 的启动、运行、停止
  • 提供用户 API 接口: 暴露简洁易用的 API 给开发者
  • 处理全局状态管理: 维护 SDK 的整体状态
  • 协调各模块间的通信: 作为模块间的通信桥梁

使用示例

import XmovAvatar from "@xmov/avatar";

const avatar = new XmovAvatar({
  container: document.getElementById("avatar-container"),
  serverUrl: "ws://localhost:8080",

// 初始化

2. ResourceManager (资源管理器)

负责管理 SDK 所需的各种资源文件。

主要功能:

  • 加载表情数据 (IBR 动画数据): 从服务器或本地加载表情动画数据
  • 管理视频资源缓存: 缓存视频资源，减少重复下载
  • 加载背景图片: 支持自定义背景图片
  • 网络质量监控: 监控网络状态，优化资源加载策略
  • 离线资源预加载: 在离线模式下使用预加载的资源

缓存策略:

  • LRU (Least Recently Used) 缓存算法: 自动淘汰最久未使用的资源
  • 自动清理过期缓存: 定期清理过期或无效的缓存
  • 内存使用限制 (默认 5MB): 防止内存溢出
  • 并发下载控制: 限制同时下载的资源数量，避免网络拥塞

实现示例

class ResourceManager {
  private cache: Map<string, CacheItem> = new Map()
  private maxCacheSize: number = 5 * 1024 * 1024 // 5MB
  private currentCacheSize: number = 0

  async loadResource(url: string, type: ResourceType): Promise<any> {
    // 检查缓存
    if (this.cache.has(url)) {
      const item = this.cache.get(url)!
      item.lastUsed = Date.now()
      return item.data
    }

    // 下载资源
    const data = await this.downloadResource(url, type)

    // 添加到缓存
    this.addToCache(url, data, type)

    return data
  }

  private addToCache(url: string, data: any, type: ResourceType): void {
    // 检查缓存大小
    while (this.currentCacheSize >= this.maxCacheSize) {
      this.evictLRU()
    }

    const size = this.calculateSize(data)
    this.cache.set(url, {
      data,
      type,
      size,
      lastUsed: Date.now()
    })
    this.currentCacheSize += size
  }

  private evictLRU(): void {
    let oldestKey: string | null = null
    let oldestTime = Infinity

    for (const [key, item] of this.cache.entries()) {
      if (item.lastUsed < oldestTime) {
        oldestTime = item.lastUsed
        oldestKey = key
      }
    }

    if (oldestKey) {
      const item = this.cache.get(oldestKey)!
      this.currentCacheSize -= item.size
      this.cache.delete(oldestKey)
    }
  }
}

3. RenderScheduler (渲染调度器)

协调所有渲染器的工作，管理渲染流程。

主要职责:

  • 调度 Avatar、Audio、UI 渲染器: 统一管理各个渲染器的渲染时机
  • 处理 TTSA 下发的数据: 将接收到的数据分发给对应的渲染器
  • 管理动画帧循环: 控制渲染帧率，优化性能
  • 控制渲染时机和顺序: 确保渲染的正确顺序和同步

渲染流程

class RenderScheduler {
  private renderers: Map<string, Renderer> = new Map()
  private animationFrameId: number | null = null
  private targetFPS: number = 30

  registerRenderer(name: string, renderer: Renderer): void {
    this.renderers.set(name, renderer)
  }

  start(): void {
    const frameInterval = 1000 / this.targetFPS
    let lastFrameTime = 0

    const renderLoop = (currentTime: number) => {
      if (currentTime - lastFrameTime >= frameInterval) {
        // 按顺序渲染
        this.renderers.forEach(renderer => {
          renderer.render()
        })
        lastFrameTime = currentTime
      }
      this.animationFrameId = requestAnimationFrame(renderLoop)
    }

    this.animationFrameId = requestAnimationFrame(renderLoop)
  }

  stop(): void {
    if (this.animationFrameId !== null) {
      cancelAnimationFrame(this.animationFrameId)
      this.animationFrameId = null
    }
  }

  scheduleData(data: RenderData): void {
    // 根据数据类型分发给对应的渲染器
    const renderer = this.renderers.get(data.type)
    if (renderer) {
      renderer.processData(data)
    }
  }
}

4. TTSA (通信模块)

处理与后端服务器的 WebSocket 通信。

通信协议:

  • Socket.IO 协议: 使用 Socket.IO 进行实时双向通信
  • MsgPack 数据序列化: 使用 MsgPack 进行高效的数据序列化
  • 支持的数据类型:
    • 音频数据
    • 表情数据
    • 身体动画数据
    • 事件数据

状态管理:

  • interactive_idle: 交互空闲状态，等待用户输入
  • listen: 监听状态，正在接收用户输入
  • think: 思考状态，处理用户输入并生成回复
  • speak: 说话状态，数字人正在说话

实现示例

import io from 'socket.io-client'
import { decode } from 'msgpack-lite'

class TTSA {
  private socket: Socket | null = null
  private state: TTSAState = 'interactive_idle'
  private eventHandlers: Map<string, Function[]> = new Map()

  async connect(serverUrl: string): Promise<void> {
    return new Promise((resolve, reject) => {
      this.socket = io(serverUrl, {
        transports: ['websocket'],
        reconnection: true,
        reconnectionAttempts: 5,
        reconnectionDelay: 1000
      })

      this.socket.on('connect', () => {
        console.log('TTSA 连接成功')
        resolve()
      })

      this.socket.on('error', (error: Error) => {
        console.error('TTSA 连接错误:', error)
        reject(error)
      })

      this.socket.on('data', (encodedData: ArrayBuffer) => {
        const data = decode(Buffer.from(encodedData))
        this.handleData(data)
      })

      this.socket.on('state', (newState: TTSAState) => {
        this.state = newState
        this.emit('stateChange', newState)
      })
    })
  }

  private handleData(data: any): void {
    const { type, payload } = data

    switch (type) {
      case 'audio':
        this.emit('audio', payload)
        break
      case 'face':
        this.emit('face', payload)
        break
      case 'body':
        this.emit('body', payload)
        break
      case 'event':
        this.emit('event', payload)
        break
    }
  }

  on(event: string, handler: Function): void {
    if (!this.eventHandlers.has(event)) {
      this.eventHandlers.set(event, [])
    }
    this.eventHandlers.get(event)!.push(handler)
  }

  private emit(event: string, data: any): void {
    const handlers = this.eventHandlers.get(event)
    if (handlers) {
      handlers.forEach(handler => handler(data))
    }
  }

  send(data: any): void {
    if (this.socket && this.socket.connected) {
      const encoded = encode(data)
      this.socket.emit('data', encoded)
    }
  }
}

5. NetworkMonitor (网络监控)

监控网络状态变化，处理离线/在线模式切换。

功能特性:

  • 自动检测网络状态: 监听浏览器的网络状态变化事件
  • 指数退避重试机制: 网络断开时采用指数退避策略重试连接
  • 网络质量监控 (RTT、带宽): 实时监控网络延迟和带宽
  • 离线模式支持: 在网络断开时切换到离线模式，使用缓存资源

实现示例

class NetworkMonitor {
  private isOnline: boolean = navigator.onLine
  private reconnectAttempts: number = 0
  private maxReconnectAttempts: number = 5
  private baseDelay: number = 1000
  private eventHandlers: Map<string, Function[]> = new Map()

  constructor() {
    this.setupListeners()
  }

  private setupListeners(): void {
    window.addEventListener('online', () => {
      this.handleOnline()
    })

    window.addEventListener('offline', () => {
      this.handleOffline()
    })
  }

  private handleOnline(): void {
    if (!this.isOnline) {
      this.isOnline = true
      this.reconnectAttempts = 0
      this.emit('networkUp')
      console.log('网络已恢复')
    }
  }

  private handleOffline(): void {
    if (this.isOnline) {
      this.isOnline = false
      this.emit('networkDown')
      console.log('网络已断开')
      this.startReconnect()
    }
  }

  private startReconnect(): void {
    if (this.reconnectAttempts >= this.maxReconnectAttempts) {
      this.emit('networkBreak')
      return
    }

    const delay = this.baseDelay * Math.pow(2, this.reconnectAttempts)
    this.reconnectAttempts++

    setTimeout(() => {
      this.emit('networkRetry', this.reconnectAttempts)
      if (navigator.onLine) {
        this.handleOnline()
      } else {
        this.startReconnect()
      }
    }, delay)
  }

  on(event: string, handler: Function): void {
    if (!this.eventHandlers.has(event)) {
      this.eventHandlers.set(event, [])
    }
    this.eventHandlers.get(event)!.push(handler)
  }

  private emit(event: string, data?: any): void {
    const handlers = this.eventHandlers.get(event)
    if (handlers) {
      handlers.forEach(handler => handler(data))
    }
  }

  getNetworkQuality(): NetworkQuality {
    // 实现网络质量检测逻辑
    return {
      rtt: this.measureRTT(),
      bandwidth: this.measureBandwidth()
    }
  }
}

错误处理示例

import { ErrorCode, SDKError } from "@xmov/avatar";

try {
  await avatar.init();
} catch (error) {
  if (error instanceof SDKError) {
    switch (error.code) {
      case ErrorCode.CONTAINER_NOT_FOUND:
        console.error("容器元素不存在，请检查 DOM 元素");
        break;
      case ErrorCode.CONNECT_SOCKET_ERROR:
        console.error("Socket 连接失败，请检查服务器地址");
        break;
      default:
        console.error("初始化失败:", error.message);
    }
  } else {
    console.error("未知错误:", error);
  }
}

常见问题及解决方案

1. 初始化失败

现象:

  • SDK 无法正常初始化
  • 容器元素不存在错误
  • WebGL 初始化失败

排查步骤:

  1. 检查容器元素是否存在

    const container = document.getElementById("avatar-container");
if (!container) {
  console.error("容器元素不存在");
}

  2. 确认浏览器支持 WebGL

    const canvas = document.createElement("canvas");
const gl =
  canvas.getContext("webgl") || canvas.getContext("experimental-webgl");
if (!gl) {
  console.error("浏览器不支持 WebGL");
}

  3. 检查网络连接

    • 确认服务器地址正确
    • 检查防火墙设置
    • 验证 WebSocket 连接是否可用

  4. 查看控制台错误信息

    • 打开浏览器开发者工具
    • 查看 Console 面板的错误信息
    • 查看 Network 面板的网络请求

2. 资源加载失败

现象:

  • 表情数据加载失败
  • 视频下载失败
  • 背景图片加载失败

排查步骤:

  1. 检查网络连接

    • 确认网络连接正常
    • 检查是否有代理设置

  2. 确认资源 URL 正确性，查看是否存在 404

    // 检查资源 URL
fetch(resourceUrl).then((response) => {
  if (!response.ok) {
    console.error("资源加载失败:", response.status);
  }
});

  3. 查看服务器响应

    • 检查服务器是否正常响应
    • 查看响应头信息
    • 确认 CORS 设置正确

  4. 检查资源文件是否存在

    • 验证文件路径
    • 确认文件权限

  5. 检查控制台表情数据是否加载失败

    • 查看调试面板的资源加载状态
    • 检查是否有错误日志

3. 音频播放问题

现象:

  • 没有声音输出
  • 音频播放延迟
  • 音频数据过期错误

排查步骤:

  1. 检查浏览器音频权限

    // 检查音频上下文状态
const audioContext = new AudioContext();
if (audioContext.state === "suspended") {
  // 需要用户交互才能播放音频
  audioContext.resume();
}

  2. 检查音频数据是否下发，根据调试面板音频下发信息查看

    • 打开调试面板
    • 查看音频数据接收状态
    • 确认音频数据格式正确

  3. 检查调试面板是否存在，音频下发过期，该错误信息会在音频数据下发晚于音频播放时间时打印

    • 查看调试面板的错误信息
    • 检查音频数据的时间戳
    • 确认音频数据同步正确

4. 渲染异常

现象:

  • 数字人不显示
  • 表情同步问题
  • 数字人卡顿

排查步骤:

  1. 检查 socket 是否连接正常，可以在控制台查看是否有上下行消息

    // 监听 Socket 消息
avatar.on("socketMessage", (data) => {
  console.log("收到消息:", data);
});

  2. 检查服务端是否下发 client_quit，客户端服务退出

    • 查看服务端日志
    • 检查是否有异常退出

  3. 检查调试面板是否有 bodyframe 或 faceframe 缺失

    • 打开调试面板
    • 查看渲染状态
    • 确认数据帧是否完整

  4. 检查视频请求是否正常

    • 查看 Network 面板
    • 确认视频资源请求成功
    • 检查视频格式是否支持

  5. 查看卡顿视频动作是否明显，部分视频可能存在无较大幅度的动作导致看起来卡顿

    • 检查视频内容
    • 确认是否为视频本身的问题
    • 尝试更换其他视频测试

5. 网络连接问题

现象:

  • WebSocket 连接失败
  • 网络重试频繁
  • 离线模式异常

排查步骤:

  1. 检查网络连接状态

    // 检查网络状态
if (!navigator.onLine) {
  console.warn("当前处于离线状态");
}

  2. 检查代理配置

    • 确认代理设置正确
    • 检查防火墙规则
    • 验证 SSL 证书

  3. 查看网络重试日志

    • 打开调试面板
    • 查看网络状态信息
    • 确认重试策略是否正常

🛠️ 调试工具使用

调试面板

SDK 提供了内置的调试面板，可以实时查看：

性能指标

  • FPS (帧率): 实时显示渲染帧率
  • 内存使用: 显示当前内存占用情况
  • 网络延迟: 显示网络往返时间 (RTT)

渲染状态

  • 当前播放的视频信息及视频对应的 bodyId: 显示当前渲染的视频资源
  • 下发的音频信息: 显示音频数据的接收和播放状态
  • 下发的事件数据: 显示事件数据的接收和处理情况

网络信息

  • 连接状态: 显示 WebSocket 连接状态
  • 数据传输量: 显示上行和下行数据量
  • 网络质量: 显示网络质量指标

启用调试面板

const avatar = new XmovAvatar({
  container: document.getElementById("avatar-container"),
  config: {
    enableDebug: true, // 启用调试面板
    debugPanelPosition: "top-right", // 调试面板位置
  },
});

调试 API

// 获取性能指标
const metrics = avatar.getPerformanceMetrics();
console.log("FPS:", metrics.fps);
console.log("Memory:", metrics.memory);

// 获取渲染状态
const renderState = avatar.getRenderState();
console.log("当前视频:", renderState.currentVideo);
console.log("音频状态:", renderState.audio);

// 获取网络信息
const networkInfo = avatar.getNetworkInfo();
console.log("连接状态:", networkInfo.connected);
console.log("网络质量:", networkInfo.quality);
