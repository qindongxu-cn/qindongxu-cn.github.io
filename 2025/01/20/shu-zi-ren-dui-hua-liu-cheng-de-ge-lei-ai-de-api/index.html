3. Agent（智能体）

3.1 Coze

接入示例：

curl -X POST 'https://api.coze.cn/v3/chat?' \
-H "Authorization: Bearer **" \
-H "Content-Type: application/json" \
-d '{
  "bot_id": "7546856028882075687",
  "workflow_id": "7546856724108673066",
  "user_id": "123456789",
  "stream": true,
  "additional_messages": [
    {
      "content": "hello",
      "content_type": "text",
      "role": "user",
      "type": "question"
    }
  ],
  "parameters": {}
}'

对接文档：

  • https://www.coze.cn/open/docs/developer_guides/chat_v3

状态：已接入

3.2 Dify

接入示例：

curl --location --request POST 'https://api.dify.ai/v1/chat-messages' \
--header 'Authorization: Bearer **' \
--header 'Content-Type: application/json' \
--data-raw '{
  "inputs": {},
  "query": "eh",
  "response_mode": "streaming",
  "conversation_id": "1c7e55fb-1ba2-4e10-81b5-30addcea2276",
  "user": "abc-123"
}'

对接文档：

  • https://docs.dify.ai/zh/use-dify/publish/developing-with-apis

状态：已接入

总结

本文档汇总了星云 DEMO 项目中接入的各类 AI 能力：

  • ASR 服务：包括腾讯、讯飞、豆包、阿里云等多个提供商的语音识别服务，支持标准模型和大模型两种类型
  • LLM 服务：集成了 Doubao、Qwen Plus、硅基流动、GLM、Kimi、DeepSeek 等多个大语言模型
  • Agent 服务：接入了 Coze 和 Dify 两个智能体平台

各服务的接入状态和详细参数已在文档中标注，开发者可根据实际需求选择合适的服务进行集成。

注意事项：

  1. 所有 API 密钥和 Token 均为敏感信息，请妥善保管，不要泄露
  2. 部分大模型 ASR 服务的接入需要进一步评估
  3. 建议在生产环境中使用环境变量管理敏感信息
  4. 定期检查 API 文档更新，确保接入方式与最新版本保持一致
