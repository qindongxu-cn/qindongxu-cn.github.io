Three.js 3D 模型渲染技术文档

一、项目概述

本项目是一个基于 Three.js 构建的 3D 模型渲染系统，支持加载和展示 GLTF/GLB 格式的 3D 模型，提供了丰富的交互功能和动画控制。

核心功能

  • ✅ GLTF/GLB 格式 3D 模型加载
  • ✅ 交互式相机控制（OrbitControls）
  • ✅ 自动旋转动画
  • ✅ 实时性能监控
  • ✅ 响应式布局设计
  • ✅ 可调节的动画速度和相机距离

二、技术架构

2.1 核心技术栈

  • Three.js: WebGL 3D 图形库
  • GLTFLoader: GLTF/GLB 模型加载器
  • OrbitControls: 轨道控制器，实现相机交互
  • ES6 Modules: 使用现代 JavaScript 模块化开发

2.2 项目结构

3dRenderDemo/
├── index.html          # 主页面文件
├── libs/               # Three.js 库文件
│   ├── three.module.js
│   ├── GLTFLoader.js
│   └── OrbitControls.js
└── ZTZ99A.glb          # 3D 模型文件

三、核心实现

3.1 模块导入与配置

项目使用 ES6 模块系统和 importmap 来管理依赖：

// importmap 配置
<script type="importmap">
{
  "imports": {
    "three": "./libs/three.module.js",
    "three/addons/": "./libs/",
    "three/examples/jsm/": "./libs/"
  }
}
</script>

// 模块导入
import * as THREE from "./libs/three.module.js";
import { GLTFLoader } from "./libs/GLTFLoader.js";
import { OrbitControls } from "./libs/OrbitControls.js";

3.2 场景初始化

3.2.1 场景创建

const scene = new THREE.Scene();
scene.background = new THREE.Color(0x87ceeb); // 天蓝色背景

3.2.2 相机设置

使用透视相机（PerspectiveCamera），模拟人眼视角：

const camera = new THREE.PerspectiveCamera(
  60, // 视野角度（FOV）
  window.innerWidth / window.innerHeight, // 宽高比
  0.1, // 近裁剪面
  1000 // 远裁剪面
);
camera.position.set(2, 2, 3); // 设置相机初始位置

参数说明：

  • FOV (60°): 视野角度，值越大视野越广
  • 宽高比: 根据窗口尺寸动态计算
  • 近/远裁剪面: 定义可见范围，超出范围的物体不渲染

3.2.3 渲染器配置

const renderer = new THREE.WebGLRenderer({ antialias: true });
renderer.setSize(window.innerWidth, window.innerHeight);
renderer.shadowMap.enabled = true; // 启用阴影映射
document.body.appendChild(renderer.domElement);

关键特性：

  • antialias: true: 启用抗锯齿，提升渲染质量
  • shadowMap.enabled: 启用阴影效果

3.3 光照系统

项目采用多光源照明方案，确保模型各个角度都有良好的光照效果：

// 前方灯光（正Z方向）
const lightFront = new THREE.DirectionalLight(0xffffff, 0.8);
lightFront.position.set(0, 2, 5);
lightFront.castShadow = true;

// 后方灯光（负Z方向）
const lightBack = new THREE.DirectionalLight(0xffffff, 0.6);
lightBack.position.set(0, 2, -5);

// 左侧灯光（负X方向）
const lightLeft = new THREE.DirectionalLight(0xffffff, 0.7);
lightLeft.position.set(-5, 2, 0);

// 右侧灯光（正X方向）
const lightRight = new THREE.DirectionalLight(0xffffff, 0.7);
lightRight.position.set(5, 2, 0);

// 环境光（提供基础照明）
const ambientLight = new THREE.AmbientLight(0xffffff, 0.4);

光照策略：

  • 方向光（DirectionalLight）: 模拟太阳光，从四个方向照射
  • 环境光（AmbientLight）: 提供整体基础亮度，避免完全黑暗的区域
  • 强度分配: 前方 0.8，左右 0.7，后方 0.6，环境光 0.4

3.4 交互控制

使用 OrbitControls 实现相机交互：

const controls = new OrbitControls(camera, renderer.domElement);
controls.enableDamping = true; // 启用阻尼效果
controls.dampingFactor = 0.05; // 阻尼系数

交互功能：

  • 鼠标左键拖拽: 旋转视角
  • 鼠标滚轮: 缩放
  • 鼠标右键拖拽: 平移视角
  • 阻尼效果: 使交互更平滑自然

3.5 模型加载

3.5.1 GLTFLoader 使用

const loader = new GLTFLoader();

loader.load(
  "./ZTZ99A.glb", // 模型文件路径
  (gltf) => {
    // 成功回调
    scene.add(gltf.scene);
    model = gltf.scene;
    // 处理模型...
  },
  (progress) => {
    // 进度回调
    const percent = ((progress.loaded / progress.total) * 100).toFixed(2);
    // 更新加载进度...
  },
  (error) => {
    // 错误回调
    console.error("加载失败:", error);
  }
);

3.5.2 模型居中与自适应

// 计算模型边界
const box = new THREE.Box3().setFromObject(gltf.scene);
const center = box.getCenter(new THREE.Vector3());
const size = box.getSize(new THREE.Vector3());

// 将模型移动到场景中心
gltf.scene.position.x = -center.x;
gltf.scene.position.y = -center.y;
gltf.scene.position.z = -center.z;

// 保存模型尺寸信息
modelSize = {
  maxDim: Math.max(size.x, size.y, size.z),
  center: center,
};

关键步骤：

  1. 使用 Box3 计算模型包围盒
  2. 获取模型中心点和尺寸
  3. 通过负偏移将模型移动到原点
  4. 保存最大尺寸用于相机定位

3.6 动画系统

3.6.1 动画循环

使用 requestAnimationFrame 实现流畅的动画：

function animate() {
  requestAnimationFrame(animate);

  const currentTime = performance.now();
  const deltaTime = (currentTime - lastTime) / 1000; // 转换为秒
  lastTime = currentTime;

  // 旋转动画
  if (model && isAnimationEnabled && rotationSpeed > 0) {
    rotationAngle += rotationSpeed * deltaTime;
    if (rotationAngle >= 360) {
      rotationAngle -= 360;
    }
    model.rotation.y = (rotationAngle * Math.PI) / 180;
  }

  controls.update();
  renderer.render(scene, camera);
}

动画原理：

  • 基于时间: 使用 deltaTime 确保动画速度不受帧率影响
  • 360 度循环: 角度超过 360° 时重置，实现无限旋转
  • 弧度转换: 将角度转换为弧度（角度 × π / 180）

3.6.2 相机位置自适应

function updateCameraPosition() {
  if (modelSize) {
    const distance = modelSize.maxDim * zoomFactor;
    camera.position.set(distance, distance * 0.6, distance);
    camera.lookAt(0, 0, 0);
    controls.target.set(0, 0, 0);
    controls.update();
  }
}

相机定位策略：

  • 根据模型最大尺寸计算距离
  • 使用 zoomFactor 控制缩放比例
  • Y 轴位置为距离的 60%，形成俯视角度
  • 相机始终朝向场景中心

3.7 响应式设计

监听窗口大小变化，动态调整渲染尺寸：

window.addEventListener("resize", () => {
  camera.aspect = window.innerWidth / window.innerHeight;
  camera.updateProjectionMatrix();
  renderer.setSize(window.innerWidth, window.innerHeight);
});

四、控制面板功能

4.1 UI 组件

控制面板提供以下功能：

  1. 动画开关: 启用/禁用自动旋转
  2. 旋转速度: 0-180 度/秒可调
  3. 镜头距离: 0.5-3.0 倍可调
  4. 加载时间: 显示模型加载耗时
  5. 页面加载时间: 显示总加载时间

4.2 事件监听

// 动画开关
animationToggle.addEventListener("change", function (e) {
  isAnimationEnabled = e.target.checked;
});

// 速度滑块
speedSlider.addEventListener("input", function (e) {
  rotationSpeed = parseFloat(e.target.value);
  speedValue.textContent = rotationSpeed.toFixed(1);
});

// 缩放滑块
zoomSlider.addEventListener("input", function (e) {
  zoomFactor = parseFloat(e.target.value);
  updateCameraPosition();
});

五、性能优化

5.1 性能监控

项目集成了性能监控功能：

// 页面加载时间
const pageLoadStartTime = performance.now();
// ...
const totalLoadDuration = pageLoadEndTime - pageLoadStartTime;

// 模型加载时间
const loadStartTime = performance.now();
// ...
const loadDuration = loadEndTime - loadStartTime;

5.2 优化建议

  1. 模型优化: 使用压缩的 GLB 格式，减少文件大小
  2. 纹理优化: 合理设置纹理分辨率
  3. LOD 技术: 根据距离使用不同细节级别的模型
  4. 阴影优化: 合理设置阴影贴图分辨率
  5. 帧率控制: 使用 requestAnimationFrame 确保流畅渲染

六、常见问题

6.1 模型加载失败

可能原因：

  • 文件路径错误
  • 文件格式不支持
  • CORS 跨域问题

解决方案：

  • 检查文件路径是否正确
  • 确保使用 GLTF/GLB 格式
  • 配置服务器 CORS 头

6.2 模型显示异常

可能原因：

  • 模型尺寸过大或过小
  • 相机位置不当
  • 光照不足

解决方案：

  • 调整 zoomFactor 参数
  • 检查模型单位设置
  • 增加环境光强度

6.3 性能问题

可能原因：

  • 模型面数过多
  • 纹理过大
  • 阴影计算开销大

解决方案：

  • 使用模型简化工具
  • 压缩纹理图片
  • 降低阴影质量或禁用阴影

七、扩展功能

7.1 可扩展方向

  • 多模型切换: 支持加载多个模型并切换
  • 材质编辑: 实时修改模型材质属性
  • 动画播放: 支持 GLTF 动画播放
  • 后处理效果: 添加抗锯齿、景深等效果
  • VR/AR 支持: 集成 WebXR API

7.2 代码示例：添加后处理

import { EffectComposer } from "three/examples/jsm/postprocessing/EffectComposer.js";
import { RenderPass } from "three/examples/jsm/postprocessing/RenderPass.js";
import { BloomPass } from "three/examples/jsm/postprocessing/BloomPass.js";

const composer = new EffectComposer(renderer);
composer.addPass(new RenderPass(scene, camera));
composer.addPass(new BloomPass(1.25, 25, 4.0, 512));

八、总结

本项目展示了如何使用 Three.js 构建一个功能完整的 3D 模型渲染系统。通过合理的架构设计、光照配置和交互控制，实现了良好的用户体验。

技术要点总结

  1. ✅ 模块化开发: 使用 ES6 Modules 组织代码
  2. ✅ 交互体验: OrbitControls 提供流畅的相机控制
  3. ✅ 性能监控: 实时显示加载和渲染性能
  4. ✅ 响应式设计: 适配不同屏幕尺寸
  5. ✅ 动画系统: 基于时间的平滑动画
